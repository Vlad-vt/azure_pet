1,200 labelled `(invoice_line, sku_id, slice)` pairs, generator `skumatch.data.synth.InvoiceLineGenerator(seed=42)`. `split=dev` (~20%) is reserved for tuning fusion weights; all reported metrics use `split=test`.

## Reproducibility

```bash
make data   # uses committed data/catalog.parquet; SKUMATCH_REFETCH=1 rebuilds from OFF
```

The generator is pure-Python and seeded; `tests/unit/test_synth.py` asserts determinism.
