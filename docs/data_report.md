Generated by `scripts/data_report.py` (`make data`). Source: [Open Food Facts](https://world.openfoodfacts.org/data) Hugging Face Parquet dump (`openfoodfacts/product-database`, ODbL 1.0).

Selection: products tagged `en:germany`, valid EAN-8/13/14, German product name, brand, parseable mass/volume quantity and an English category tag; ranked by `unique_scans_n` (popularity) and de-duplicated on normalised `brand + name + quantity`.

## Synthetic invoice benchmark (`data/golden_eval.jsonl`)

1,200 labelled `(invoice_line, sku_id, slice)` pairs, generator `skumatch.data.synth.InvoiceLineGenerator(seed=42)`. `split=dev` (~20%) is reserved for tuning fusion weights; all reported metrics use `split=test`.

| Slice | Lines | dev | test | Most frequent transforms |
|---|---|---|---|---|
| `abbreviations` | 300 | 69 | 231 | `truncate` (152), `brand_code` (141), `skeleton` (115), `dict_abbrev` (34) |
| `unit_swap` | 300 | 77 | 223 | `unit_rewrite` (300), `qty_first` (88) |
| `ocr_typos` | 300 | 68 | 232 | `char_confusion` (187), `article_no` (158), `char_drop` (151), `noise_token` (132) |
| `hard_negatives` | 300 | 75 | 225 | `sibling_in_catalog` (300), `unit_rewrite` (244), `truncate_shared` (102) |

## Reproducibility

```bash
make data   # uses committed data/catalog.parquet; SKUMATCH_REFETCH=1 rebuilds from OFF
```

The generator is pure-Python and seeded; `tests/unit/test_synth.py` asserts determinism.
